# 厕纸抽卡 · M1

一卷厕纸，按住画面往下拖，纸带跟着出来，每过一段算一格。这一版只做交互层，
没有撕裂、没有角色卡、没有镜头演出。

## 跑起来

```sh
npm install
npm run dev
```

`npm run build` 会先跑 `tsc --noEmit` 再打包。

## 目录

- `src/params.ts` — 所有可调参数。`PAPER` 是道具的固定尺寸，`params` 是手感参数。
- `src/paper/feed.ts` — 手感的核心：拖动距离怎么变成纸带长度，松手之后发生什么。
- `src/input/drag.ts` — pointer 事件折成一个标量「拉了多少像素」，不碰纸。
- `src/scene/` — Three.js 场景、纸张贴图、卷纸与纸带几何。
- `src/ui/lab.ts` — 左下角的参数面板。

## 左下角的参数

| 参数 | 含义 |
| --- | --- |
| 拖拽灵敏 | 多少像素换一个世界单位的纸。数值越小越容易拉过。 |
| 跟手刚度 | 纸带追上指针的速度。大了是硬跟手，小了有橡皮筋的延迟。 |
| 松手惯性 | 松手后保留多少速度。0 是立刻停。 |
| 一段长度 | 一格纸的长度，同时决定卷身上虚线绕几圈。 |
| 最多段数 | 拉满是多少格。 |
| 摆动幅度 | 纸带横向飘动的幅度，按当前速度缩放。 |
| 允许回卷 | 关掉后纸带只进不退。 |
| 松手吸附到格位 | 松手后自动对齐到整格。 |

「重置纸带」把纸收回、计数归零。
